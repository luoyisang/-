# My First Git & GitHub Practice
> GitHub入门练习仓库

## 📖 项目简介
本仓库用于练习Git与GitHub基础操作，包含git克隆、提交、分支、推送等基础流程。

## ✨ 练习内容
1. GitHub账号注册，个人主页配置
2. 本地Git环境使用，clone拉取远程仓库
3. git add / commit / push 基础提交操作
4. 分支创建、切换、合并练习
5. 编写README文档，规范仓库说明

## 🛠 使用步骤
```bash
# 克隆仓库到本地
git clone https://github.com/luoyisang/my-first-git-practice.git

# 进入项目文件夹
cd my-first-git-practice

# 修改文件后提交
git add .
git commit -m "描述本次修改内容"
git push origin main
